页面没有正常启动

如果是从文件管理器直接双击打开的：file:// 下 Chrome / Edge / Firefox 都会拦掉模块加载， 这条路走不通。双击项目里的 启动预览.bat（或在项目目录里执行 node scripts/serve.mjs 5173）， 再访问 http://localhost:5173/index.html 即可。

如果是刚装了一个自制模块之后才打不开的：在地址后面加上 ?nomods=1 （即 http://localhost:5173/index.html?nomods=1）就能跳过所有自制模块先启动， 进去之后在设置 → 模块里把那一条删掉。
