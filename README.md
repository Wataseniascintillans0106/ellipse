# ellipse · 日常状态记录

面向有身体疾病人群的手机端日常记录工具。零依赖、零构建的静态网页：数据全部保存在本机浏览器，
可导出为 Obsidian 风格的 md 文件。

当前完成的是**功能框架**，视觉细节与图标（svg）留待后续打磨。

---

## 一、怎么打开它

这个项目是**纯静态网页**（没有服务器、没有数据库、没有构建步骤），
所以「打开它」其实就是「把这个文件夹放到一个网址上」。四种方式，按需要选：

| # | 方式 | 适合谁 | 手机上能用吗 | 断网可用 |
| --- | --- | --- | --- | --- |
| ① | **部署到 GitHub Pages**（推荐） | 想长期用、给手机装上 | ✅ 装到主屏，就是个 App | ✅ |
| ② | 部署到 Cloudflare Pages / Netlify / Vercel | 仓库不想公开 | ✅ 同上 | ✅ |
| ③ | 电脑上本地起服务器（`启动预览.bat`） | 改代码时看效果 | 手机连 Wi-Fi **只能看版式** | ❌ |
| ④ | 直接双击 `index.html` | —— | ❌ **打不开**，见下 | ❌ |

**一句话结论**：自己用、给手机装 → 走 ①；改代码 → 用 ③。④ 这条路是死的。

---

### ① 部署到 HTTPS（手机用户走这条）

部署完你会得到一个 `https://` 开头的网址。手机浏览器打开它 → 「添加到主屏幕」，
之后就像 App 一样：全屏、有图标、断网也能记。

以免费的 **GitHub Pages** 为例：

1. 把项目推上 GitHub（做法见 [docs/版本管理.md](docs/版本管理.md)）；
2. 仓库页 → **Settings** → 左侧 **Pages**；
3. **Source** 选 `Deploy from a branch`，**Branch** 选 `main`，
   右边的目录框选 **`/(root)`**（⚠️ **别选 `/docs`** —— 本项目恰好有个 `docs/`
   文件夹，选错会得到一个 404 的空站，还很难看出为什么）；
4. 保存后等 1～3 分钟，Pages 页面顶部会给出网址，形如
   `https://<你的用户名>.github.io/ellipse/`。

> 免费账号的 GitHub Pages 只能用于**公开仓库**。仓库必须是公开的，或者改用 ②。
> 不用担心记录泄露：记录只在你自己手机的浏览器里，**从来不是项目文件**。

**如果 GitHub Pages 打不开或很慢**，换 ② 里任意一家，做法完全一样
（连上仓库 → 选分支 → 自动部署），只要最后给你一个 `https://` 网址就行。

#### 为什么必须 HTTPS

浏览器有条安全规矩：**离线缓存、安装到主屏这类能力只授权给「安全来源」**，
而安全来源只有两种——`https://` 网址，和电脑自己访问自己的 `http://localhost`。

所以手机连同一个 Wi-Fi 访问 `http://192.168.x.x:5173` 时，
Service Worker、离线缓存、「安装到主屏」全都不生效。那不是 bug。

#### 以后怎么更新

`git push` → 等一两分钟 → 手机上重新打开就是新版。**不需要重新安装**，
主屏那个图标一直用同一个网址。

> 只有一个例外：**如果新增或删除了文件**（或者改了 `sw.js` 本身），记得把里面的
> `CACHE` 版本号 +1（现在是 `ellipse-cache-v6`，下次改成 `v7`），并把新文件补进
> `SHELL` 清单。只改
> `index.html` / `assets/` / `fonts/` 下**已有**文件的内容不用管。原因见
> [docs/PWA部署与安装.md](docs/PWA部署与安装.md) 第五节。

### ② 部署到别的免费静态托管

同样免费、自带 HTTPS、**支持私人仓库**，做法和 GitHub Pages 差不多：

- [Cloudflare Pages](https://pages.cloudflare.com/)
- [Netlify](https://www.netlify.com/)
- [Vercel](https://vercel.com/)

共同点：**只要最后给你一个 `https://` 网址就行**，剩下的部署步骤和权限限制完全一样。

### ③ 电脑上本地预览（改代码时用）

**Windows 上最简单：双击项目里的 `启动预览.bat`。**
它会起好本地服务器并自动打开浏览器。
（第一次用需要先装 [Node.js](https://nodejs.org) 的 LTS 版本；没装的话脚本会提示你。）

手动起也一样：

```powershell
node scripts/serve.mjs 5173
```

- 电脑打开：<http://localhost:5173/index.html>
- 手机打开：手机与电脑连同一个 Wi-Fi，浏览器访问 `http://<电脑局域网IP>:5173/index.html`

> ⚠️ **手机连 Wi-Fi 只能看版式**：局域网 HTTP 不是「安全来源」，
> 离线缓存、安装到主屏在这里都不会生效。
> 要试这些功能，请按 ① 部署到 HTTPS（电脑上的 `http://localhost:5173` 则可以正常测）。
>
> 要停止预览：关掉那个标题是 `ellipse-server` 的黑色命令行窗口。

**示例数据（可选）**：打开 <http://localhost:5173/scripts/seed.html> 会写入 90 天示例记录并跳回首页。
清除数据：设置 → 数据 → 清空全部记录。

### ④ 直接双击 `index.html` —— 不行

这个项目用的是 ES module，而 `file://` 下 **Chrome / Edge / Firefox 全都会拦掉模块加载**
（只有 Safari 宽松）。症状是一片空白加一句「页面没有正常启动」。

**必须经 `http://` 或 `https://` 打开。** 用 ③ 的 `.bat`，或按 ① 部署。

---

### ⚠️ 换网址 = 换一份数据

这条很容易踩，单独说：**浏览器把数据按「网址」分开存放**。
`http://localhost:5173`、`https://a.github.io/ellipse/`、`https://b.netlify.app/`
在这三者里看到的是**三份互不相通的数据**。

所以：

- 部署到新网址后，旧网址里记的东西**不会跟过去**。迁移只能用设置 → 数据里的 **备份 JSON**：
  在旧网址「备份 JSON」→ 在新网址「导入备份」。
- 反过来，只要你一直用同一个网址，更新代码、重装到主屏，数据都还在。

（更完整的说明在 [docs/PWA部署与安装.md](docs/PWA部署与安装.md)。）

### 以后想做成 APK？

目前**还没有 APK**，也不建议一开始就做。三条路，按投入从少到多：

| 路线 | 怎么做 | 代价 |
| --- | --- | --- |
| **A. 继续用 PWA**（推荐先走这条） | 什么都不用做。装到主屏后就是全屏、有图标、能离线 | 上不了应用商店；iOS 上体验略逊于原生 |
| **B. 包一层壳（TWA）** | 用 [PWABuilder](https://www.pwabuilder.com/) 或 Bubblewrap，把已部署的 PWA 打包成 APK。内容还是从你的 HTTPS 网址加载 | **必须先有 ① 的 HTTPS 网址**；要签名；能上 Google Play |
| **C. 把整个项目打进 APK** | 用 [Capacitor](https://capacitorjs.com/) 把 `assets/` 一起打包，完全不依赖网络 | 以后**每次改代码都要重新打包发版**，不能再"push 一下就更新"；国内安卓商店上架一般还要软件著作权等材料 |

**为什么推荐先走 A**：PWA 和 APK 的体验差别主要就是"能不能上商店"。
但更新方式差很多——A 是 `git push` 一下、所有人下次打开就是新版；
B 和 C 都得重新走一遍打包和安装。**先把 A 跑通，真需要上商店了再考虑 B。**

## 二、页面结构

三层。主页保持 [docs/demo.html](docs/demo.html) 的样子，状态记录是它的下一层，
「状态波动图」这类**页面型模块**自己也占一整页：

1. **主页**：只有字标；右下角是**设置**按钮，右侧竖栏里是各入口 ——
   「状态记录」和各个**页面型模块**的入口（默认是「状态波动图」「日历及健康」「弦音」，
   从上到下：状态波动图 → 日历及健康 → 弦音 → 状态记录），
   先后顺序在设置里逐行排（见 [七、设置页](#七设置页只在主页右下角齿轮) 第 1 条）。
   在设置里关掉某个模块，竖栏里对应的入口就消失；把「状态记录」那一栏的模块全部关掉，
   「状态记录」入口也一起收起 —— 再打开其中任何一个，它就回来。
   字标、设置按钮、右侧竖栏三样在任何情况下都不动，主页永远是这一块。
2. **状态记录**（点竖栏最下面那个图标进入）：
   - 顶部是日期，下面按设置的顺序排列各模块的栏；
   - 记录页左右内边距相等（各 26px），内容在屏幕中居中；
   - **右上角是返回主页按钮**；
   - 没有设置按钮：**设置只在主页**；也没有右侧竖栏（导出入口在页面底部）；
   - 手机系统返回键 / 浏览器返回键同样能退回主页。
3. **模块自己的整页**（点竖栏里**上面**那些图标进入，如「状态波动图」）：
   - 框架与状态记录页完全一致：同样左右各 26px、同样可整页上下滑、同样右上角是返回按钮；
   - 标题取模块的名字（左上角），内容由模块自己画，最下面一行小字也由模块自己写；
   - 同样没有设置按钮、没有竖栏。

地址：主页 `index.html#home`，记录页 `index.html#record`，模块整页 `index.html#page/<模块id>`
（如 `index.html#page/trend`）—— 都可刷新、可分享。
前缀 `#page/` 是必要的：模块的 id 有可能是 `record` 或 `home`，直接拼上去会和前两层撞名。

## 三、已经实现的模块

| 栏 | 记录内容 | 波状图 |
| --- | --- | --- |
| 情绪 | 醒后 / 睡前心情，1–10 评分 | 醒后、睡前、日内变化（睡前−醒后）三条 |
| 睡眠 | 睡眠质量 1–10，睡眠时长（小时） | 质量、时长两条 |
| 疼痛 | 疼痛程度 0–10，部位/备注 | 疼痛程度一条 |
| 运动 | 运动时长（分钟，可手填或用快捷键），是否不适 | 运动时长一条 |
| 微成就 | 今天做到的小事，一行一条 | 无（纯文字模块不生成图表） |
| 日记 | 纯文本 | 无（纯文字模块不生成图表） |
| 状态波动图 | 不出记录，只把上面各模块的评分汇成曲线 | 它不在记录页，自己在主页竖栏占一个入口 |
| 日历及健康 | 把服药、就医、复诊、体检排到日子上（见下节） | 它不在记录页，自己在主页竖栏占一个入口 |
| 弦音 | 不出记录，自己在主页竖栏占一个入口，进去是一整页聊天 | 无（页面型模块，不占记录页） |

- 日期条**左边是前一天、右边是后一天**（时间由左至右，今天在轴的右端，到今天就点不动了），
  点日期本身可跳到最近有记录的某天，在记录页上左右滑动也能切换日期。
- 每一天的栏从上到下排列，点标题栏展开 / 收起。
- 记录页最下面是导出入口：预览当天的 md，可复制或下载。

## 四、状态波动图

- **它不在记录页**，而是主页右侧竖栏里的一个图标，点开是**自己的一整页**；
  页面框架与记录页一致（能整页上下滑，右上角返回按钮，最下面一行小字）。
  它在竖栏里的位置由设置里的**主页右侧栏顺序**决定（默认它排在最上面）；
  在设置里关掉它，竖栏里这个入口就消失。
- 区间可切 **7 天 / 1 个月 / 3 个月**（设置里可改默认区间）。
- 点任意数据点，显示「日期 · 数值」。**只有有记录的那天才画圆点。**
- **没记录的日子照样在横轴上占一格，按「最低」画在底部**：整条折线是连续的，
  往下贴到底的那一段就是空着的日子（不是「那几天分数很低」的意思）。
  分辨办法看圆点：**有圆点 = 真记了这一天的数**，没圆点 = 那天没记。
  （所以疼痛记成 0 分和完全没记录都贴在最底下，靠圆点区分。）
- 按记录页的栏顺序排列；**在设置里关掉的模块，这里的图一起消失**（数据仍保留在本机）。
- 这一页只读：图上点选、切区间都不会改动任何记录。

## 五、日历及健康

主页竖栏里「状态波动图」下面那个入口，点开是自己的一整页：

- **一本月历**（一周七格，从周日还是周一开始可在设置里选）。今天那格用实心圆
  圈出来，有安排的日子底下点几个小色点。左右箭头翻月，也可以一键回到本月。
  点某一天，格子下面列出那天的安排。
- **列表视图**：把往后 60 天的安排按天排成一条列，不用一天天翻。两种视图在页面顶上切换，
  **打开先看哪个**在设置里定。
- **加一项**：右下角一个加号（或在某天下面点「在这天加一项」），先问是哪种日程。
- **搜索**：右上角的放大镜，按药名、医院、备注里的词搜，点结果直接跳到那天。
- **日程类型**：内置四个 ——
  | 类型 | 记什么 |
  | --- | --- |
  | 服药 | 药名 / 药品公司、基本单位与每次剂量、饭前 · 饭中 · 饭后、具体几点、频率 |
  | 就医 | 医院、科室、医生、时间、频率 |
  | 复诊 | 医院、医生、时间、频率 |
  | 体检 | 医院 / 机构、项目、时间、频率 |

  频率四种：**只此一次 / 每天 / 隔几天（天数自己填）/ 每几小时（小时数自己填）**。
  「每几小时」从起始时刻往后数，所以会跨过半夜（早上八点开始、每八小时一次，
  第二天是零点、八点、十六点）；「隔几天 / 隔几周 / 隔几月」按真实日历推，
  每月 31 号那种碰上二月会自动落到 28 / 29 号。
- **自己加类型**：设置 · 模块 · 日历及健康 →「新增日程类型」——起名字、挑图标、
  挑颜色、勾要哪些栏、勾支持哪些频率。存下来它就排进那一栏，和内置的四个一样能开关、
  能排日程，还多「编辑」「删除」两个按钮（编辑只改样子，已排的日程不动；
  删除会连它的日程一起没，所以先问一句）。
- **提醒**：到点了发系统通知（第一次开这个开关时浏览器会问一次授权），页面里也同时弹一条提示，
  点通知会回到这一页。同一条日程一天只提醒一次。
- **什么类型都不开的时候，它就是一本普通的日历**：照常能看、能翻、能搜，
  只是加不了那些类型的日程。日程只保存在这台设备上，不上传。

## 六、弦音

主页**右侧竖栏**里的一个入口（默认排在「日历及健康」下面、「状态记录」上面），
点开是**自己的一整页聊天**。它不占记录页，也不占主页任何地方 ——
关掉它，主页和你以前看到的一字不差。

- **要不要它，你说了算**：设置 → 模块 → 关掉「弦音」，竖栏里的入口和设置里那一块
  **一起消失**。想再要，打开就是 —— 入口还会回到原来那一行的位置。
- **整屏聊天，输入条钉在底部**：只有消息列表在中间滚，输入条和下面那行免责小字
  固定在最底下。手机上弹软键盘时按真实可视高度算，输入条不会被键盘顶跑。
- **能发照片**：输入框左边那个圆按钮，点了选照片（手机上会让你挑「拍照 / 相册」）。
  选完先贴在输入条上面，右上角有「×」可以撤掉 —— **点了「发送」才真的发**。
  发出去之后气泡里有照片，**点一下能弹出来看大图**。
  在内存里缩成两张：**发给 AI 的那张**长边不超过 1568（清楚，但**不落盘**），
  **存本机的那张**长边不超过 480（大概 25~45 KB）。原图不落盘、不上传。
  本机放不下了就从**最旧**的照片开始丢，只丢照片、文字留着，气泡上写
  「（这张照片没有留底）」。竖着拍的照片会按 EXIF 摆正，不会被放倒。
  ⚠️ 设置里没改过的话，兜底接口是 DeepSeek，它的模型**看不了图片** ——
  这种情况会出一张卡直说「这个模型看不了图片」，让你去换一个支持图片的
  （比如 `gpt-4o` 或 `gpt-4o-mini`），而不是丢一句「接口返回 400」。
- **它要动你的数据，一定先问**：填一条状态记录、加一条日程、改一条日程、删一条日程，
  都会先弹一张卡，写明要动哪一天、哪个模块、改成什么。点「同意」才真的写进去。
  加日程和填记录**没有**「以后不用再问」的例外，每次都得点。
- **它看不看得到你的记录，你说了算**：设置里有总开关
  「允许弦音读取我的记录」，**默认是关的**；开着的时候它想看仍然先出卡，
  卡上写清楚要看哪几天、哪几个模块、一共几天，卡上还有一个勾
  「这几个模块以后不用再问」，勾了才免掉下一次的卡。
  一轮对话里它最多读一次、总共最多三次请求，超了会明说「这一轮已经读过一次了」。
- **谁问它才答**：你不发消息，它不会自己开口。整个聊天区里除了你说的话和它的回复，
  不会凭空冒出别的东西。
- **输入框下面常驻一行小字**：「弦音不是医生，说的话不能替代医嘱。内容由 AI 生成，
  仅供参考，只辅助记录，不做任何医学判断。」（回复气泡下面不再重复。）
- **自伤的话，本地先拦住**：像「不想活了」这样的话**一个字节都不会发出去**，
  直接给一张固定的求助卡（12356 心理援助热线 / 主治医生 / 120 · 110）。
  护栏也写进了每次请求都带的系统提示词：不做医疗建议、不诊断、不建议改药。
- **聊天记录留在本机**：导出的**一键备份会带上它**（备份里不会出现你的密钥）；
  设置里还有「导出弦音聊天 md」，导出来是一份按天分段、分得清谁说的、也记下了
  哪条执行了的 md；带过照片的那条会标一个「［照片］」（照片本身不进 md）。
- **「该导出一份了」是 App 在提醒你，不是弦音在说话**：超过 14 天没导出、而且这期间
  确实又记了新东西，设置按钮上会冒一个小圆点，设置 → 数据 里多一行字写清楚
  隔了多少天。导出或备份之后圆点自己消失，旁边有「先不用提醒」（点了 30 天不再提）。
- **想让它排在别处**：设置 → 模块 → 展开 **AI——弦音** 那一折（**主页右侧栏顺序**
  就住在里面），每一行一个入口、后面跟着「上移 / 下移」（第一行和最后一行
  对应的那个按钮是灰的）。

> ⚠️ **这是本项目唯一一处让数据离开你这台机器的地方。**
> 用弦音意味着：**你打的字、你贴的照片、之前的聊天记录**会发到你填的那个 AI 接口；
> **状态记录只在你点过同意之后才发**。不打开弦音，就什么都不会外发。

## 七、设置页（只在主页，右下角齿轮）

1. **模块** —— 所有模块都在同一个列表里，内置的和自己导入的没有区别：
   每个都有开关、**导出**；自己导入的还多一个**卸载**（内置的不能卸）。
   模块按栏分组：**数值图 → 日历及健康 → AI——弦音 → 状态记录**，
   每一栏的标题条右边各有一个**总开关**（那一栏只有一个模块时不显示），
   点一下就把该栏的模块一股脑开 / 关。
   关闭的模块不出现在记录页，对应的波状图同步隐藏；把「状态记录」栏里的模块全部关掉，
   主页右侧竖栏的「状态记录」入口也一起收起（再打开其中任何一个，它就回来）。
   「日历及健康」那一栏里是五个开关（日历自己 + 服药 / 就医 / 复诊 / 体检），
   栏里还有一个**新增日程类型**按钮；日程类型自带「编辑」「删除」两个按钮，
   所以它们没有「导出源码」（那些类型没有自己的源文件，是设置里存出来的）。
   能上记录页的模块（记录型、面板型）才有**上移 / 下移**按钮，用来调记录页上的先后；
   服务型模块和「状态波动图」「日历及健康」「弦音」这类**页面型模块**不占记录页的位置，
   所以没有排序按钮 —— 页面型模块的入口在主页右侧竖栏里，关掉它入口就跟着消失。
   顶部还有 **导入模块** 按钮。详见 [八、模块系统](#八模块系统)。

   有三样设置不自己占一节，而是**挂进它管的那一栏里**：
   - **波状图默认区间**（由「状态波动图」模块提供）住在**数值图**那一折，
     展开就能看到那三个区间按钮；
   - **弦音自己的设置**（可选，见 [六、弦音](#六弦音)）住在**AI——弦音**那一折。
     展开这一折，从上到下依次是：
     - 接口地址：OpenAI 兼容地址，如 `https://api.deepseek.com` 或 `https://api.openai.com/v1`
     - API Key：**只保存在本机 localStorage**，直接从浏览器请求接口，不经过任何中间服务器
     - 模型（默认 `gpt-4o-mini`）。**要发照片就得填一个能看图的模型**
       （比如 `gpt-4o` / `gpt-4o-mini`），默认那个接口的模型看不了图
     - **允许弦音读取我的记录**：总开关，**默认关着**（见 [六、弦音](#六弦音)）
     - 「测试连接」：当场问一句接口通不通
     - 「导出弦音聊天 md」「清空弦音聊天」
     - 非可信域名的接口地址，浏览器可能直接拒绝跨域请求（设置页会提示）
     - **关掉「弦音」模块，上面这些和竖栏里的聊天入口会一起消失**
       （那一折本身还在，因为「主页右侧栏顺序」住在里面）
   - **主页右侧栏顺序**也住在**AI——弦音**那一折：竖栏里每个入口占一行（图标 + 名字），
     后面跟着「上移 / 下移」两个小按钮 —— 这是唯一一处能调竖栏先后顺序的地方，
     第一行的「上移」和最后一行的「下移」是灰的。关掉某一栏，它就从这一列里
     自动消失，再打开又回到原来那一行。

     它之所以跟弦音放一块儿，是因为这一折里列的就是「竖栏里点得进去的那几栏」，
     顺序表挨着它们，看的时候一眼能对上号。弦音这个模块被卸掉时，
     它也不会跟着丢，会自动退回「模块」最底下单独占一节。
2. **日历** —— 打开先看月还是列表、一周从哪天开始、要不要到点提醒
   （这一块由「日历及健康」模块提供；把日历那一栏关光，这一块也跟着消失）。
3. **数据** —— 导出今天 md / 全部 md / 区间汇总 md（含统计与表格）/ 备份 JSON / 导入备份（合并或覆盖）/ 清空记录。
   导出的文件不会出现你的 AI 密钥。
   备份 JSON 里的「备份包含 AI 密钥」**默认不勾**：要发给别人时保持不勾。
   这一块最上面可能有**导出提醒**那一行（见 [六、弦音](#六弦音)），平时不显示。

## 八、模块系统

整个应用（包括内置的情绪、睡眠、弦音）都是由**模块**拼起来的，装模块就像给游戏装 mod：
设置 → 模块 → 导入模块 → 选一个 `.js` 文件，就多一栏功能。

- **导入**：选本地 `.js` 文件。会先弹确认框，告诉你这个模块**自称**的 id 与名字，再决定装不装。
- **导出**：把任意模块的源码取回来（内置的也行）。想改内置模块，导出来改完再导回去就是你的了。
- **禁用**：关掉开关，那一栏从记录页消失，**数据仍留在本机**。再打开就回来了。
- **卸载**：删掉模块代码。会问一句要不要连它记录的数据一起删，**默认不删**。
- **更新**：同一个 `id` 再导入一次就是更新，不会变成两份。

> ⚠️ **模块就是一段能在你浏览器里运行的代码。** 它能读到本机保存的全部记录和
> 你填的 AI 密钥，也能把它们发到任何地方去。所以**只装你自己写的、或你能看懂并且
> 信得过的人给的 `.js` 文件**。这是所有「可装模块」系统的固有代价，不是本项目的缺陷。

装了一个写坏的模块（语法错误、死循环）怎么办：

- 语法错、执行出错 → 设置 → 模块里多一条「加载失败」的条目，写明原因，一键删掉即可，其余功能照常。
- **死循环卡死页面** → 在地址后面加 `?nomods=1`（如 `http://localhost:5173/index.html?nomods=1`），
  跳过全部自制模块先启动，进去把它删掉。设置里也有「停用全部自定义模块」。

想自己写一个模块？契约、字段类型、示例代码、安全须知都在
**[docs/mod开发指南.md](docs/mod开发指南.md)**。

## 九、文件与数据

导出 md 的文件名就是当天日期，可直接放进 Obsidian 库：

```markdown
---
date: 2026-09-27
weekday: 周日
tags: [ellipse, 状态记录]
modules: [mood, sleep, pain, exercise, micro, diary]
---

# 2026年09月27日 周日

## 情绪

- 醒后：5 / 10
- 睡前：7 / 10

## 睡眠

- 睡眠质量：6 / 10
- 睡眠时长：7.5 小时

## 微成就

- 多走了五分钟
- 把药按时吃完了

## 日记

上午在小区里慢走了二十分钟，膝盖比上周轻。
```

浏览器本地存储的键：

| 键 | 内容 |
| --- | --- |
| `ellipse.v1.records` | 全部记录，按 `YYYY-MM-DD` 分组 |
| `ellipse.v1.settings` | 模块开关 / 顺序 / 默认区间 / 各模块自己的配置（含 AI 配置）；**日历的日程也在这里**（`settings.mods[日程类型].events`）；竖栏排行在 `settings.ui.railOrder`；**弦音的聊天记录（含照片缩图）也在 `settings.mods.assistant.chat`** |
| `ellipse.v1.mods` | 自己导入的模块源码（下次打开页面时重新装载） |
| `ellipse.v1.calRemind` | 日历提醒的记账：今天已经提醒过哪几条（只当天有效，用来避免重复提醒） |
| `ellipse.v1.remind` | 导出提醒的记账：上次导出是几号、免打扰到哪天 |

> 清理浏览器数据会一并清空，请定期在设置里备份 JSON。
> 第一、第二行是会被备份带走的；`calRemind`、`remind` 是记账，不算数据。

导出的 md 有两种：按天的记录，和**弦音的聊天记录**
（文件名形如 `ellipse-chord-2026-10-10.md`，按天分段、分得清谁说的、也记下了哪条执行了）。

## 十一、如何再加一个模块

**想给自己用**：写一个 `.js` 文件，在设置里导入即可，不用改本仓库任何代码——
见 [docs/mod开发指南.md](docs/mod开发指南.md)。一个完整的模块长这样：

```js
ellipse.define({
    apiVersion: 1,
    id: 'weight', name: '体重', icon: 'chart', desc: '每天同一时间称重',
    fields: [
        { key: 'kg', type: 'number', label: '体重', unit: 'kg', step: 0.1, chips: [55, 60, 65] }
    ]
});
```

记录页那一栏、收起时的摘要、md 导出、波状图曲线，全部由这句声明自动推导出来。

**想做成内置的**：把上面这份文件放进 `assets/js/modules/`，在
`assets/js/modules/index.js` 里加一行 `import './weight.js';`，再去 `sw.js` 的
`SHELL` 清单里补上这个文件路径。`node scripts/smoke.mjs` 会检查预缓存清单有没有漏文件。

## 十二、测试

```powershell
node scripts/smoke.mjs          # 逻辑：记录读写、波状图、md 导出、默认设置、模块安装/卸载/导出的往返、
                                #       日历日程的日期推算（每天 / 隔几天 / 隔几周 / 每月 / 每几小时）
```

浏览器交互自检，起好服务器后打开：

- <http://localhost:5173/scripts/flowcheck.html> —— 真实操作流程
  （进记录页、展开栏、从竖栏进「状态波动图」页并切区间、开关导出面板、设置里排竖栏顺序、
  顺带核对设置里谁住哪一折：波状图的默认区间归到「数值图」那一折、
  弦音的设置和栏位顺序都归到「AI——弦音」那一折，
  设置里不再有孤零零一节叫「显示」，也不再有两个「AI——弦音」标题，
  以及日历：排一条日程 → 列表视图 → 搜索 → 详情删除 → 翻月 → 自定义日程类型的增删，
  以及弦音：从竖栏进它那一页 → 把网络请求换成假的喂一段流式回话 → 气泡出来 →
  指令块从没以文字形式露出 → 确认卡出来 → 点同意才真的写进去 →
  贴一张照片（画出来的真 png）→ 预览条 → 发出去 → 请求体里确实带了图、气泡里有图、
  存本机的那条只留小的那张、临时那张没落盘 → 看不了图的模型说人话 →
  坏文件被挡住且没惊动网络 → 关掉模块竖栏里入口消失）
- <http://localhost:5173/scripts/modcheck.html> —— 模块系统闭环
  （装一个模块 → 记录 → 导出 md → 导出源码 → 卸载 → 数据仍在 → `?nomods=1` 逃生舱）

两个页面都会把每条结果打在页面上，方便改动后回归。
（`flowcheck` 里 `ok` 就是通过，末尾的 `DONE` 表示整段跑完了 —— 有 `FAIL` 或 `ERROR` 才是出问题了。）

## 十四、隐私

记录**不出本机**：没有账号、没有服务器、没有埋点。数据只写进浏览器的 localStorage，
AI 功能（可选）由浏览器直接请求你自己填的接口地址，不经过任何中间服务器。

**唯一一处例外是弦音**：用弦音意味着**你打的字、你贴的照片和聊天记录，都会发到你填的那个
AI 接口；状态记录只在你点过同意后才发**。不打开弦音，就什么都不会外发。
（照片只有缩过的那张小图留在本机，原图不落盘。）详见 [六、弦音](#六弦音)。

三点需要注意：

- **同一台设备的同一个浏览器**才看得到同一份数据。电脑上记的和手机上记的是两份，
  不会自动同步；换浏览器、开无痕窗口同样看不到。跨设备迁移只能靠「备份 JSON」手动导入。
- 清理浏览器数据（或卸载浏览器）会**一并清空**记录，请定期在设置里导出备份。
- 你自己导入的模块**拥有这个页面的全部权限**，能读到本机全部记录和 AI 密钥。
  这是「可装模块」的固有代价，所以只装你信得过的 `.js` 文件；
  备份 JSON 默认不含密钥，就是为了让它能安全地发给别人。
