# ellipse · 日常状态记录

面向有身体疾病人群的手机端日常记录工具。零依赖、零构建的静态网页：数据全部保存在本机浏览器，
可导出为 Obsidian 风格的 md 文件。

当前完成的是**功能框架**，视觉细节与图标（svg）留待后续打磨。

---

## 一、怎么打开它

这个项目是**纯静态网页**（没有服务器、没有数据库、没有构建步骤），
所以「打开它」其实就是「把这个文件夹放到一个网址上」。四种方式，按需要选：

| # | 方式 | 适合谁 | 手机上能用吗 | 断网可用 | 语音转写 |
| --- | --- | --- | --- | --- | --- |
| ① | **部署到 GitHub Pages**（推荐） | 想长期用、给手机装上 | ✅ 装到主屏，就是个 App | ✅ | ✅ |
| ② | 部署到 Cloudflare Pages / Netlify / Vercel | 仓库不想公开 | ✅ 同上 | ✅ | ✅ |
| ③ | 电脑上本地起服务器（`启动预览.bat`） | 改代码时看效果 | 手机连 Wi-Fi **只能看版式** | ❌ | ❌ |
| ④ | 直接双击 `index.html` | —— | ❌ **打不开**，见下 | ❌ | ❌ |

**一句话结论**：自己用、给手机装 → 走 ①；改代码 → 用 ③。④ 这条路是死的。

---

### ① 部署到 HTTPS（手机用户走这条）

部署完你会得到一个 `https://` 开头的网址。手机浏览器打开它 → 「添加到主屏幕」，
之后就像 App 一样：全屏、有图标、断网也能记。

以免费的 **GitHub Pages** 为例：

1. 把项目推上 GitHub（做法见 [docs/版本管理.md](docs/版本管理.md)）；
2. 仓库页 → **Settings** → 左侧 **Pages**；
3. **Source** 选 `Deploy from a branch`，**Branch** 选 `main`，
   右边的目录框选 **`/(root)`**（⚠️ **别选 `/docs`** —— 本项目恰好有个 `docs/`
   文件夹，选错会得到一个 404 的空站，还很难看出为什么）；
4. 保存后等 1～3 分钟，Pages 页面顶部会给出网址，形如
   `https://<你的用户名>.github.io/ellipse/`。

> 免费账号的 GitHub Pages 只能用于**公开仓库**。仓库必须是公开的，或者改用 ②。
> 不用担心记录泄露：记录只在你自己手机的浏览器里，**从来不是项目文件**。

**如果 GitHub Pages 打不开或很慢**，换 ② 里任意一家，做法完全一样
（连上仓库 → 选分支 → 自动部署），只要最后给你一个 `https://` 网址就行。

#### 为什么必须 HTTPS

浏览器有条安全规矩：**麦克风只授权给「安全来源」**，而安全来源只有两种——
`https://` 网址，和电脑自己访问自己的 `http://localhost`。

所以手机连同一个 Wi-Fi 访问 `http://192.168.x.x:5173` 时，**麦克风授权永远弹不出来**，
语音转写按钮按了没反应。那不是 bug。同一原因，Service Worker、离线缓存、
「安装到主屏」在这些地址下也全都不生效。

#### 以后怎么更新

`git push` → 等一两分钟 → 手机上重新打开就是新版。**不需要重新安装**，
主屏那个图标一直用同一个网址。

> 只有一个例外：**如果改动了 `sw.js` 本身，记得把里面的 `CACHE` 版本号 +1**
> （现在是 `ellipse-cache-v2`，下次改成 `v3`）。只改 `index.html` / `assets/` /
> `fonts/` 下的内容不用管。原因见 [docs/PWA部署与安装.md](docs/PWA部署与安装.md) 第五节。

### ② 部署到别的免费静态托管

同样免费、自带 HTTPS、**支持私人仓库**，做法和 GitHub Pages 差不多：

- [Cloudflare Pages](https://pages.cloudflare.com/)
- [Netlify](https://www.netlify.com/)
- [Vercel](https://vercel.com/)

共同点：**只要最后给你一个 `https://` 网址就行**，剩下的部署步骤和权限限制完全一样。

### ③ 电脑上本地预览（改代码时用）

**Windows 上最简单：双击项目里的 `启动预览.bat`。**
它会起好本地服务器并自动打开浏览器。
（第一次用需要先装 [Node.js](https://nodejs.org) 的 LTS 版本；没装的话脚本会提示你。）

手动起也一样：

```powershell
node scripts/serve.mjs 5173
```

- 电脑打开：<http://localhost:5173/index.html>
- 手机打开：手机与电脑连同一个 Wi-Fi，浏览器访问 `http://<电脑局域网IP>:5173/index.html`

> ⚠️ **手机连 Wi-Fi 只能看版式**：局域网 HTTP 不是「安全来源」，
> 离线缓存、安装到主屏、麦克风授权在这里都不会生效。
> 要试这些功能，请按 ① 部署到 HTTPS（电脑上的 `http://localhost:5173` 则可以正常测）。
>
> 要停止预览：关掉那个标题是 `ellipse-server` 的黑色命令行窗口。

**示例数据（可选）**：打开 <http://localhost:5173/scripts/seed.html> 会写入 90 天示例记录并跳回首页。
清除数据：设置 → 数据 → 清空全部记录。

### ④ 直接双击 `index.html` —— 不行

这个项目用的是 ES module，而 `file://` 下 **Chrome / Edge / Firefox 全都会拦掉模块加载**
（只有 Safari 宽松）。症状是一片空白加一句「页面没有正常启动」。

**必须经 `http://` 或 `https://` 打开。** 用 ③ 的 `.bat`，或按 ① 部署。

---

### ⚠️ 换网址 = 换一份数据

这条很容易踩，单独说：**浏览器把数据按「网址」分开存放**。
`http://localhost:5173`、`https://a.github.io/ellipse/`、`https://b.netlify.app/`
在这三者里看到的是**三份互不相通的数据**。

所以：

- 部署到新网址后，旧网址里记的东西**不会跟过去**。迁移只能用设置 → 数据里的 **备份 JSON**：
  在旧网址「备份 JSON」→ 在新网址「导入备份」。
- 反过来，只要你一直用同一个网址，更新代码、重装到主屏，数据都还在。

（更完整的说明在 [docs/PWA部署与安装.md](docs/PWA部署与安装.md)。）

### 以后想做成 APK？

目前**还没有 APK**，也不建议一开始就做。三条路，按投入从少到多：

| 路线 | 怎么做 | 代价 |
| --- | --- | --- |
| **A. 继续用 PWA**（推荐先走这条） | 什么都不用做。装到主屏后就是全屏、有图标、能离线 | 上不了应用商店；iOS 上体验略逊于原生 |
| **B. 包一层壳（TWA）** | 用 [PWABuilder](https://www.pwabuilder.com/) 或 Bubblewrap，把已部署的 PWA 打包成 APK。内容还是从你的 HTTPS 网址加载 | **必须先有 ① 的 HTTPS 网址**；要签名；能上 Google Play |
| **C. 把整个项目打进 APK** | 用 [Capacitor](https://capacitorjs.com/) 把 `assets/` 一起打包，完全不依赖网络 | 以后**每次改代码都要重新打包发版**，不能再"push 一下就更新"；国内安卓商店上架一般还要软件著作权等材料 |

**为什么推荐先走 A**：PWA 和 APK 的体验差别主要就是"能不能上商店"。
但更新方式差很多——A 是 `git push` 一下、所有人下次打开就是新版；
B 和 C 都得重新走一遍打包和安装。**先把 A 跑通，真需要上商店了再考虑 B。**

## 二、页面结构

两层。主页保持 [docs/demo.html](docs/demo.html) 的样子，状态记录是它的下一层：

1. **主页**：只有字标；右下角是**设置**按钮，右侧竖栏里是「状态记录」入口（与 demo 一致）。
2. **状态记录**（点竖栏图标进入）：
   - 顶部是日期，下面按设置的顺序排列各模块的栏；
   - 记录页左右内边距相等（各 26px），内容在屏幕中居中；
   - **右上角是返回主页按钮**；
   - 没有设置按钮：**设置只在主页**；也没有右侧竖栏（导出入口在页面底部）；
   - 手机系统返回键 / 浏览器返回键同样能退回主页。

地址：主页 `index.html#home`，记录页 `index.html#record`（可刷新、可分享）。

## 三、已经实现的模块

| 栏 | 记录内容 | 波状图 |
| --- | --- | --- |
| 情绪 | 醒后 / 睡前心情，1–10 评分 | 醒后、睡前、日内变化（睡前−醒后）三条 |
| 睡眠 | 睡眠质量 1–10，睡眠时长（小时） | 质量、时长两条 |
| 疼痛 | 疼痛程度 0–10，部位/备注 | 疼痛程度一条 |
| 运动 | 运动时长（分钟，可手填或用快捷键），是否不适 | 运动时长一条 |
| 日记 | 纯文本，可语音转写、可交 AI 整理 | 无（纯文字模块不生成图表） |
| 状态波动图 | 不出记录，只把上面各模块的评分汇成曲线 | 默认展开；可在设置里关闭 |

- 日期条两个箭头都在左侧（前 / 后一天，未来日期不可选），点日期本身可跳到最近有记录的某天，
  在记录页上左右滑动也能切换日期。
- 每一天的栏从上到下排列，点标题栏展开 / 收起；「状态波动图」默认保持展开。
- 记录页最下面是导出入口：预览当天的 md，可复制或下载。

## 四、状态波动图

- 就是记录页最后一条栏，和「情绪」「睡眠」同一种形态，**默认展开**，点标题栏可收起。
- 区间可切 **7 天 / 1 个月 / 3 个月**（设置里可改默认区间）。
- 点任意数据点，显示「日期 · 数值」；缺记录的日期用虚线段断开。
- 按记录页的栏顺序排列；**在设置里关掉的模块，这里的图一起消失**（数据仍保留在本机）。
- 整条栏也可以在设置里关闭。

## 五、设置页（只在主页，右下角齿轮）

1. **模块** —— 所有模块都在同一个列表里，内置的和自己导入的没有区别：
   每个都有开关、上移下移、**导出**；自己导入的还多一个**卸载**（内置的不能卸）。
   记录型模块至少保留一个。关闭的模块不出现在记录页，对应的波状图同步隐藏。
   顶部还有 **导入模块** 按钮。详见 [六、模块系统](#六模块系统)。
2. **显示** —— 波状图默认区间（这一块由「状态波动图」模块提供）。
3. **AI 辅助**（可选，由「AI 助手」模块提供）
   - 接口地址：OpenAI 兼容地址，如 `https://api.deepseek.com` 或 `https://api.openai.com/v1`
   - API Key：**只保存在本机 localStorage**，直接从浏览器请求接口，不经过任何中间服务器
   - 模型 / 转写模型（默认 `gpt-4o-mini` / `whisper-1`）
   - 填了 Key：录音 → 上传转写 → AI 整理成日记
   - 没填 Key：用浏览器内置语音识别，识别结果直接写入日记
   - 非可信域名的接口地址，浏览器可能直接拒绝跨域请求（设置页会提示）
   - **关掉「AI 助手」模块，这个分区和日记里的两个按钮会一起消失**
4. **数据** —— 导出今天 md / 全部 md / 区间汇总 md（含统计与表格）/ 备份 JSON / 导入备份（合并或覆盖）/ 清空记录。
   备份 JSON 里的「备份包含 AI 密钥」**默认不勾**：要发给别人时保持不勾。

## 六、模块系统

整个应用（包括内置的情绪、睡眠、AI 助手）都是由**模块**拼起来的，装模块就像给游戏装 mod：
设置 → 模块 → 导入模块 → 选一个 `.js` 文件，就多一栏功能。

- **导入**：选本地 `.js` 文件。会先弹确认框，告诉你这个模块**自称**的 id 与名字，再决定装不装。
- **导出**：把任意模块的源码取回来（内置的也行）。想改内置模块，导出来改完再导回去就是你的了。
- **禁用**：关掉开关，那一栏从记录页消失，**数据仍留在本机**。再打开就回来了。
- **卸载**：删掉模块代码。会问一句要不要连它记录的数据一起删，**默认不删**。
- **更新**：同一个 `id` 再导入一次就是更新，不会变成两份。

> ⚠️ **模块就是一段能在你浏览器里运行的代码。** 它能读到本机保存的全部记录和
> 你填的 AI 密钥，也能把它们发到任何地方去。所以**只装你自己写的、或你能看懂并且
> 信得过的人给的 `.js` 文件**。这是所有「可装模块」系统的固有代价，不是本项目的缺陷。

装了一个写坏的模块（语法错误、死循环）怎么办：

- 语法错、执行出错 → 设置 → 模块里多一条「加载失败」的条目，写明原因，一键删掉即可，其余功能照常。
- **死循环卡死页面** → 在地址后面加 `?nomods=1`（如 `http://localhost:5173/index.html?nomods=1`），
  跳过全部自制模块先启动，进去把它删掉。设置里也有「停用全部自定义模块」。

想自己写一个模块？契约、字段类型、示例代码、安全须知都在
**[docs/mod开发指南.md](docs/mod开发指南.md)**。

## 七、文件与数据

导出 md 的文件名就是当天日期，可直接放进 Obsidian 库：

```markdown
---
date: 2026-09-27
weekday: 周日
tags: [ellipse, 状态记录]
modules: [mood, sleep, pain, exercise, diary]
---

# 2026年09月27日 周日

## 情绪

- 醒后：5 / 10
- 睡前：7 / 10

## 睡眠

- 睡眠质量：6 / 10
- 睡眠时长：7.5 小时

## 日记

上午在小区里慢走了二十分钟，膝盖比上周轻。
```

浏览器本地存储的键：

| 键 | 内容 |
| --- | --- |
| `ellipse.v1.records` | 全部记录，按 `YYYY-MM-DD` 分组 |
| `ellipse.v1.settings` | 模块开关 / 顺序 / 默认区间 / 各模块自己的配置（含 AI 配置） |
| `ellipse.v1.mods` | 自己导入的模块源码（下次打开页面时重新装载） |

> 清理浏览器数据会一并清空，请定期在设置里备份 JSON。

## 九、如何再加一个模块

**想给自己用**：写一个 `.js` 文件，在设置里导入即可，不用改本仓库任何代码——
见 [docs/mod开发指南.md](docs/mod开发指南.md)。一个完整的模块长这样：

```js
ellipse.define({
    apiVersion: 1,
    id: 'weight', name: '体重', icon: 'chart', desc: '每天同一时间称重',
    fields: [
        { key: 'kg', type: 'number', label: '体重', unit: 'kg', step: 0.1, chips: [55, 60, 65] }
    ]
});
```

记录页那一栏、收起时的摘要、md 导出、波状图曲线，全部由这句声明自动推导出来。

**想做成内置的**：把上面这份文件放进 `assets/js/modules/`，在
`assets/js/modules/index.js` 里加一行 `import './weight.js';`，再去 `sw.js` 的
`SHELL` 清单里补上这个文件路径。`node scripts/smoke.mjs` 会检查预缓存清单有没有漏文件。

  （进记录页、展开栏、切区间、开关导出面板、设置里关栏）
- <http://localhost:5173/scripts/modcheck.html> —— 模块系统闭环
  （装一个模块 → 记录 → 导出 md → 导出源码 → 卸载 → 数据仍在 → `?nomods=1` 逃生舱）

两个页面都会把每条结果打在页面上，方便改动后回归。

## 十二、隐私

记录**不出本机**：没有账号、没有服务器、没有埋点。数据只写进浏览器的 localStorage，
AI 功能（可选）由浏览器直接请求你自己填的接口地址，不经过任何中间服务器。

三点需要注意：

- **同一台设备的同一个浏览器**才看得到同一份数据。电脑上记的和手机上记的是两份，
  不会自动同步；换浏览器、开无痕窗口同样看不到。跨设备迁移只能靠「备份 JSON」手动导入。
- 清理浏览器数据（或卸载浏览器）会**一并清空**记录，请定期在设置里导出备份。
- 你自己导入的模块**拥有这个页面的全部权限**，能读到本机全部记录和 AI 密钥。
  这是「可装模块」的固有代价，所以只装你信得过的 `.js` 文件；
  备份 JSON 默认不含密钥，就是为了让它能安全地发给别人。
